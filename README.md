# Any Domestic Help — Premium Demo

Lightweight static demo (~30 KB). No Node.js or npm required.

## Open locally

```bash
cd /Users/huzaifaansari/Downloads/anydomestic
python3 -m http.server 8765
```

Then visit: **http://localhost:8765**

Or double-click `index.html` in Finder.

## What's included

- Premium hero with search bar
- Trust badges & animated stats
- Service cards with pricing
- Featured professional profiles
- How it works timeline
- Why choose us, testimonials, FAQ
- Contact form & hire modal (demo toasts)
- Floating WhatsApp / call buttons
- Fully responsive

## Demo note

Forms show success toasts only. To connect live PHP backend later, point form POSTs to `eprocess.php` on your server.
